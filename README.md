# Homework special 1

Збірка коротких вправ на Python: арифметика, умови, цикл `while`, перетворення типів. Кожна вправа окремо виводить результат у консоль.

## Запуск

```bash
python homework_special_1.py
```

## Як це працює

### Розминка

1. Арифметика. Для `a = 17` і `b = 5` виводяться сума, різниця, добуток і ділення: `22 / 12 / 85 / 3.4`.
2. Ділення націло і остача. `a // b` дає цілу частину (`3`), `a % b` дає остачу (`2`).
3. Степені. `2**10` дорівнює `1024`, `10**3` дорівнює `1000`.
4. Вартість покупки. Ціна `249.99` множиться на кількість `3`.
5. Типи результатів ділення. `7/2` має тип `float`, `7//2` має тип `int`, `7.0//2` знову `float`, бо один з операндів дробовий.
6. Рядки. `"Python"*3` повторює рядок тричі, а `+` склеює `"Привіт"` і `"світ"` без пробілу.

### Обчислення

7. Ряди учнів. `28 // 6` дає `4` ряди, `28 % 6` дає `4` учні, що залишаються.
8. Секунди в хвилини і години. `3725 / 60` дає хвилини, `3725 / 60**2` дає години (дробові значення).
9. Хвилини в години і секунди. `150 / 60` дає `2.5` години, `150 * 60` дає `9000` секунд.
10. Цельсій у Фаренгейт. За формулою `C * 9/5 + 32`.
11. Прямокутник. Площа `a * b`, периметр `(a + b) * 2`.
12. Коло. Площа `pi * r**2`, довжина `2 * r * pi`, де `pi = 3.14159`.
13. Знижка. Від суми віднімається її частка: `1200 - 1200 * 0.15 = 1020`.
14. Зарплата після податку. Те саме для податку `19.5%`: `25000 - 25000 * 0.195`.
15. Відстань. Швидкість множиться на час: `90 * 2.5 = 225`.
16. Півсума трьох чисел. `(a + b + c) / 2` дає `14.5`. Для сторін трикутника це півпериметр.
17. Парність. `n % 2 == 1` означає непарне число, `n % 2 == 0` означає парне. Для `7` виводиться «Число непарне».
18. Остання цифра. `n % 10` повертає остачу від ділення на 10, для `473` це `3`.
19. Цифри трицифрового числа. Сотні: `n // 100`. Десятки: `(n % 100) // 10`. Одиниці в коді рахуються як `(n % 100) % 7`, для `473` це `3`, але збіг випадковий. Правильно було б `n % 10`.
20. Сума цифр. Та сама ідея для `859`, але одиниці знову рахуються через `% t` замість `% 10`, тому замість `22` виводиться `17`. Виправлення: `n % 10`.
21. Розворот числа. Цикл `while` бере останню цифру (`num % 10`), дописує її справа до `rev` (`rev * 10 + dg`) і відкидає її з числа (`num // 10`). Для `123` виходить `321`.
22. Квадратний корінь. `a ** 0.5` дає `12.0` для `144`.
23. Секунди в році. `365 * 24 * 60 * 60 = 31536000`.

### Типи даних

24. Рядки і числа. `"5" + "3"` дає рядок `"53"`, а `int("5") + int("3")` дає число `8`.
25. Перетворення в `int`. `int(9.99)` відкидає дробову частину і дає `9`.
26. Булеві значення як числа. `True` дорівнює `1`, `False` дорівнює `0`, тому `True+True+True` дає `3`, а `True*10` дає `10`.
27. Складені присвоєння. З `a = 5` і `b = 10`: `b -= a` дає `b = 5`, `a += a` дає `a = 10`. Виводиться `10 5`.
28. Складні відсотки. `deposit * (1 + rate)**years` для `10000`, `12%` і `3` років дає `14049.28`.
29. Розділювач і `str()`. `"-" * 20` друкує лінію з двадцяти дефісів, `str(2**20)` перетворює `1048576` на рядок.
